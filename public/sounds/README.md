# Custom Notification Sounds Folder

Place your `.mp3`, `.wav`, or `.ogg` sound files directly into this directory (`public/sounds/`).

### How It Works:
1. Copy your downloaded ringtone or sound file into this folder (e.g. `notification.mp3`, `alert.mp3`, `doorbell.mp3`).
2. Open the **Notification Ringtone & Sound Settings** modal in the top navigation bar or ticket dashboard.
3. Your custom sound file will automatically be detected and listed in the sound selection grid!
4. You can preview, set volume, and assign it to **New Ticket Sound** or **Chat Message Sound**.
